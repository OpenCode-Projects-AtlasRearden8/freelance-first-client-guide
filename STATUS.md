# STATUS.md

Last verified: October 29, 2026

## What was built

**The First-Client Survival Kit** — a plain-English manual for landing and surviving a first freelance client, delivered as:

- **8 guide chapters** in `docs/` (Markdown, the canonical source):
  `00-start-here`, `01-services-one-pager`, `02-quoting-projects`, `03-simple-contracts`, `04-invoices-that-get-paid`, `05-scope-guarding`, `06-testimonials`, `07-when-llc-makes-sense`
- **3 print-and-use companions** in `docs/`: `quote-worksheet`, `invoice-checklist`, `glossary`
- **Static HTML site** generated by `build.py` (zero dependencies, Python stdlib only) into `site/` — one page per document, with chapter navigation, prev/next pagers, print stylesheet, disclaimer asides, and Markdown tables/blockquotes/lists/inline formatting
- `README.md`, MIT `LICENSE` (Copyright (c) 2026 Asdale Dynamics, LLC), `.gitignore`

Stance throughout: education only, never legal or tax advice; disclaimers appear on the home page and in the contracts and LLC chapters.

## How to run it

```sh
python3 build.py          # rebuild site/ from docs/
python3 build.py --test   # self-tests: markdown renderer checks + page checks
```

Then open `site/index.html` in any browser. No server, no network, no frameworks.

## Known gaps / future work

- Inline diagram/emoji-free styling only — no images yet; a portfolio-page chapter and a "finding your first three clients" outreach chapter are natural additions
- The renderer supports a deliberately common subset of Markdown (no nested lists, no images, no footnotes); extend `md_to_html` in `build.py` if future chapters need more
- No dark mode; the print stylesheet hides navigation, which is most of what a print reader needs
- Chapter 7 deliberately avoids state-specific rules (e.g. Indiana filing specifics) — that depth belongs to the companion **llc-first-year-handbook**
- The tests check rendered structure, not typographic beauty — a visual pass in a browser is worth doing before any real-world sharing
